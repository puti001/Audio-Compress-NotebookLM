# Puti-AI | 錄音極致壓縮工具（語音辨識 / NotebookLM 專用）

> 專為演講錄音、上課錄音、會議紀錄設計的極限壓縮小工具。將原本 2~3 小時約 200~300MB 的龐大音訊/影片檔，在**不損害人聲清晰度**的前提下，極速壓縮至 **約 40~50MB**，並自動命名為 `檔名_人聲.m4a`，方便直接上傳至 Google NotebookLM 或各類 AI 轉逐字稿工具。

## 🚀 功能特色
* **極簡操作**：無需安裝複雜軟體，拖曳即轉檔。
* **多檔批次**：支援一次框選多個檔案同時拖入排隊處理。
* **支援多種格式**：支援 `.mp3`, `.wav`, `.m4a`, `.mp4`, `.aac`, `.flac` 等常見格式。
* **體積極致瘦身**：原 300MB 檔案壓縮後約 40MB，大幅節省雲端空間與上傳時間。

## 🔬 壓縮原理與參數說明

音訊體積公式：
$$\text{檔案大小} = \text{位元率 (Bitrate)} \times \text{時間長度 (秒)} \div 8$$

### 核心最佳化策略：
1. **雙聲道轉單聲道 (`-ac 1`)**：
   * 一般錄音為立體聲（Stereo，左右兩軌），轉為單聲道（Mono）**直接省下 50% 容量**，且完全不影響語音辨識精準度。
2. **語音專用位元率 (`-c:a aac -b:a 32k`)**：
   * 音樂需 192k~320k，但人聲語音在 32kbps AAC 下即可保持極佳字詞清晰度。
   * **3 小時 (10,800 秒) $\times$ 32 kbps $\div$ 8 $\approx$ 42.2 MB**。
3. **最佳人聲取樣率 (`-ar 24000`)**：
   * 人聲頻率主要落於 8kHz 以下，取樣率設為 24,000Hz 既能完整保留語音細節，又能減少編碼雜訊與檔案負擔。
4. **去除影像軌 (`-vn`)**：
   * 若拖入的是影片檔（如 `.mp4`），自動剔除影像，僅抽取並壓縮純人聲音訊。
